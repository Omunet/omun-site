        Politique de confidentialité

        Ce site n'utilise ni cookies, ni analyse d'audience, ni publicité.

        Ce site ne conserve pas les données du formulaire. Si vous écrivez par le formulaire de contact, le prénom, le nom si vous l'indiquez, le courriel, le téléphone si vous l'indiquez, le message et les fichiers sont envoyés par courrier. La finalité est de répondre à la demande. La base légale est votre consentement, que vous pouvez retirer quand vous voulez. Le prénom, le courriel et le message sont nécessaires pour pouvoir répondre. Le message et les fichiers ne sont gardés que le temps nécessaire pour traiter la demande, puis supprimés.

        Si vous avez moins de 14 ans, l'autorisation de votre père, de votre mère ou de votre tuteur est nécessaire.

        N'envoyez pas de données sensibles, ni de photos ou de vidéos d'autres personnes sans leur autorisation.

        Il est hébergé sur GitHub Pages (GitHub, Inc., États-Unis), qui peut enregistrer l'adresse IP des visiteurs pour la sécurité et le fonctionnement, conformément à la déclaration de confidentialité de GitHub et au cadre de protection des données UE–États-Unis.

        La langue que vous choisissez n'est enregistrée que dans votre navigateur (localStorage) et vous pouvez l'effacer à tout moment.

        Vous pouvez utiliser ce formulaire pour exercer les droits d'accès, de rectification, d'effacement, d'opposition, de limitation et de portabilité. Vous pouvez aussi introduire une réclamation auprès de l'Agence espagnole de protection des données (www.aepd.es).
